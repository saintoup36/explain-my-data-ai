# ExplainMyData AI

ExplainMyData AI is an interactive data analysis and visualization tool built with Streamlit, powered by AI.

## 🚀 Features
- Upload CSV, Excel, TXT, or DOCX files
- Automatic data profiling and cleaning suggestions
- Interactive dashboards and charts
- AI-powered insights with business recommendations
- Translation support for global users
- Export results (CSV, PDF, translated text)

## 🧠 Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib
- ReportLab
- OpenAI API

## 📊 How It Works
1. Upload your dataset or document  
2. Explore data overview and quality insights  
3. Generate AI-powered analysis  
4. Visualize trends using charts  
5. Export results or ask follow-up questions  

## 🔐 Security
API keys are stored securely using environment variables and are not included in this repository.
